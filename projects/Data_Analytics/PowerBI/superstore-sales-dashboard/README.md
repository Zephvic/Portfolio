# 📊 SuperStore Sales Performance Dashboard (Power BI) *(Coming Soon)*

An interactive Power BI dashboard built on the SuperStore dataset, featuring dynamic KPIs, year-over-year comparisons, and Top N filtering.

---

## 📌 Planned Features

- **KPI Cards** — Total Sales, Total Profit, Profit Margin, YoY % Change
- **Sales by Category & Sub-Category** — bar charts with Top N filter
- **Monthly Sales Trend** — line chart with proper month ordering via Calendar table
- **Regional Performance Map**
- **Customer Segment Breakdown**
- **Slicers** — Year, Region, Category, Segment

---

## 🛠️ Tools

- **Power BI Desktop**
- **DAX** — custom measures (YoY delta, rolling totals, margin %)
- **Calendar Table** — for correct time intelligence
- **Custom PNG Background** — for polished dashboard layout
