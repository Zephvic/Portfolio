# 👥 Customer Segmentation & Sales Analysis *(In Progress)*

A Python project using clustering techniques to segment customers by purchasing behavior and demographics, enabling targeted business strategies.

---

## 📌 Objectives

- Explore and clean a retail customer dataset
- Apply RFM analysis (Recency, Frequency, Monetary)
- Cluster customers using K-Means
- Visualize segments and derive actionable insights

---

## 🛠️ Tools & Libraries

- Python · Pandas · NumPy
- Scikit-learn (K-Means clustering)
- Matplotlib · Seaborn
- Jupyter Notebook
