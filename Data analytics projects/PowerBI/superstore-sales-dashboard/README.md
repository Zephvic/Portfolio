## Description

An interactive Power BI dashboard on the SuperStore dataset, built around dynamic KPIs, year-over-year comparisons, and Top N filtering by category and region.

## Planned Features

- KPI cards for total sales, total profit, profit margin, and YoY % change
- Bar charts for sales by category and sub-category, with a Top N filter
- A line chart for monthly sales trend, using a calendar table for correct ordering
- A regional performance map
- A breakdown by customer segment
- Slicers for year, region, category, and segment

## Tools and Technologies

- Power BI Desktop
- DAX — custom measures (YoY delta, rolling totals, margin %)
- Calendar table — for correct time intelligence
- Custom PNG background for the dashboard layout
